# Cybersecurity HomeLab

## Project Overview

Welcome to my Cybersecurity HomeLab!

This repository documents my journey building and managing a hands-on cybersecurity home lab to develop practical experience in networking, system administration, virtualization, and information security.

As a cybersecurity student, my goal is to apply classroom knowledge to real-world technical environments while developing skills relevant to IT infrastructure and cybersecurity operations.

My HomeLab consists of two primary systems:

- **Raspberry Pi:** Dedicated to network security, DNS filtering, monitoring, and Linux administration.
- **Proxmox Server (Old Gaming PC):** A repurposed gaming computer that will host virtual machines for cybersecurity testing, Windows and Linux administration, and virtual networking.

This repository will track my progress from initial planning through implementation, including configurations, troubleshooting, challenges, and lessons learned.

## HomeLab Infrastructure

### Raspberry Pi — Network Security

**Planned projects:**
- Install and configure Raspberry Pi OS
- Configure SSH for secure remote management
- Deploy Pi-hole for network-wide DNS filtering
- Monitor network activity
- Implement Linux security hardening

### Proxmox Server — Virtualization

**Planned projects:**
- Install and configure Proxmox VE
- Deploy Windows and Linux virtual machines
- Build a Windows Server Active Directory environment
- Practice virtual networking and network segmentation
- Implement security monitoring
- Create an isolated cybersecurity testing environment

## Project Objectives

- Develop practical Linux and Windows administration skills
- Gain experience managing virtual machines and servers
- Understand networking, DNS, and security configurations
- Practice security monitoring and troubleshooting
- Learn cybersecurity best practices
- Build a documented technical portfolio

## Security Considerations

All cybersecurity testing will be performed in authorized environments.

Security practices will include:

- Isolating intentionally vulnerable virtual machines
- Applying operating system and software updates
- Using strong authentication
- Restricting unnecessary network access
- Protecting sensitive configurations and credentials
- Following responsible cybersecurity testing practices
