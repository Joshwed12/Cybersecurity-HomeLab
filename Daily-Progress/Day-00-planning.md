# Day 00 — Cybersecurity HomeLab Planning

**Project Status:** Planning  
**Phase:** 1 — Infrastructure Preparation

## Project Overview

The purpose of this project is to develop hands-on experience in cybersecurity, networking, Linux administration, virtualization, and security monitoring.

This home lab will use two separate devices: a Raspberry Pi dedicated to networking and security services, and a repurposed gaming PC functioning as a virtualization server.

Throughout this project, I will document my progress, technical configurations, challenges, troubleshooting steps, and lessons learned.

## Hardware and Infrastructure

### Device 1 — Raspberry Pi

**Purpose:** Network security and infrastructure services

**Planned implementations:**
- Install and configure Raspberry Pi OS
- Configure SSH for remote administration
- Deploy Pi-hole for DNS filtering and network-wide ad blocking
- Implement network monitoring tools
- Explore Linux system hardening

### Device 2 — Gaming PC Server

**Purpose:** Virtualization and cybersecurity testing

**Planned implementations:**
- Install Proxmox Virtual Environment
- Create Windows and Linux virtual machines
- Build a virtual networking environment
- Configure a Windows Server Active Directory lab
- Practice system administration and security monitoring
- Develop an isolated environment for cybersecurity testing

## Project Objectives

1. Gain practical experience administering Linux and Windows operating systems.
2. Understand virtualization technologies and virtual networking.
3. Develop network security and monitoring skills.
4. Build familiarity with cybersecurity tools and security configurations.
5. Practice technical documentation and troubleshooting.
6. Create a portfolio demonstrating practical cybersecurity knowledge.

## Security Considerations

Before deploying services, I will consider the following:

- Keep operating systems and applications updated.
- Change default credentials and use strong authentication.
- Restrict unnecessary network access.
- Isolate intentionally vulnerable virtual machines from my home network.
- Avoid publishing sensitive information, credentials, or private network configurations.
- Document security controls and configuration changes.
